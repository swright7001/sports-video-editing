# Sports Video Editing

For sports highlights, athlete showcases, game recaps, and music-driven edits. Includes action selection, tracking, speed changes, replay continuity, sound design, and quality checks.

This repository contains one self-contained Codex skill. Copy this directory into your Codex skills directory to install it. Read `SKILL.md` for the workflow. It is an instructional skill using available tools, not a bundled renderer or transcription service.

## Start a project

After installing the skill, start with a prompt such as:

> Use $sports-video-editing to help me make an athlete highlight reel from my footage.

The skill starts with a short conversation about the athlete and jersey number, intended audience, edit style, footage location and delivery needs. It remembers established answers and checks available tools before recommending anything extra.

The workflow includes a representative sample, readable athlete markers, gentle tracking where appropriate, complete-play selection, source-aware quality adjustments and export checks. Recruiting showcases and music-driven reels can use different treatments. Editing software, footage, music and paid services are not bundled with the skill.

Preserve original footage and prior exports. External uploads and publishing require applicable authorization. Do not commit footage, private transcripts, credentials, or generated project outputs here.
