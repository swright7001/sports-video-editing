# New-project intake

## A short first conversation

Start with a plain introduction such as: “I’ll identify the athlete, review the footage, make a short sample, then build and check the full edit.” Adapt it to the request. Ask at most three compact questions in the first round, combining related details and omitting anything already known:

1. **Who and why?** Who are the highlights for, what sport/team, and who will watch—coaches/recruiters, family, fans, or social followers? For one athlete, ask for their name and jersey number, including different numbers or uniforms across teams/events. Request roster or supplied photo context only if needed to establish identity.
2. **What should it feel like?** Recruiting showcase, energetic music reel, game recap, or multiple versions? Ask which comes first, approximate length, landscape/portrait or viewing platform, and any must-include moments or reference edits. Offer a recommendation if they are unsure.
3. **Where is the footage and how should we work?** Ask for the footage location, preferred editing app if any, deadline, and delivery destination/device. Ask about required tools or budget only when an actual capability is missing or paid/cloud processing is being considered; do not make the user choose codecs or install software as part of intake.

For a minimal request, ask just for the athlete/jersey, footage location and intended audience first. Save optional music, graphics and delivery questions until relevant. If a text-only question tool is used, do not ask for uploads or screenshots through that tool.

## Follow up only where it changes the work

- **Identity:** Check jersey, team/event and continuity in the footage. A shared number across different teams is not sufficient on its own. If uncertainty remains, show a short candidate clip or still for confirmation before labeling that athlete. Save the confirmed mapping. Do not identify by facial similarity alone.
- **Style:** Offer a gentle-follow versus tighter-crop comparison if useful. For recruiting, suggest readable normal-speed plays, restrained graphics and original court/field sound. For a music reel, establish genre/energy and supplied or authorized music. These are recommendations, not fixed defaults.
- **Titles:** Ask for graduation year, position and any desired contact details only when needed. Include height, statistics, GPA or accolades only if provided/verified for this project; do not assume a website's older profile is current. Do not reuse a delivery email as a public recruiting contact without authorization.
- **Tools:** Inspect available local editors, FFmpeg/ffprobe and relevant connectors first. Explain any actual missing capability and the available options in plain language. Installing a tool, starting a trial, buying a plan or uploading footage is not implied by an editing preference. Existing authorization still applies.
- **Quality/storage:** Inspect resolution, frame rate, HDR/SDR, audio, free disk space and existing copies. Explain demonstrated limitations. If cleanup becomes necessary, distinguish replaceable caches/verified duplicate archives from originals and preserve source footage.
- **Delivery:** Establish whether the user needs an inline preview, local master, downloadable link or actual MP4 attachment. Verify the recipient from session context and obtain sending authorization if absent. Do not repeat permission already granted.

## Save a compact project brief

Record the athlete/jersey mapping and its evidence, audience, priority between versions, length/aspect ratio, accepted crop/marker treatment, title facts, audio/music choice, quality target, source locations, tool constraints, deadline and delivery preferences. Mark unknowns explicitly. Keep names, email addresses, exact source timestamps and one-off styling choices in the project, not in this reusable skill.

End intake with a concise working brief and the next concrete action. Proceed on authorized reversible work; a sample review is an editorial checkpoint, not a new approval requirement for every step.
